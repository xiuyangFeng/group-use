# 文件保险箱 0.6.0 发布说明

- 发布日期：2026-11-05
- 在 0.5.1（见 [发布说明-0.5.1](发布说明-0.5.1.md)）基础上：密码改简单，忘记密码改用密保问题

## 密码：任意 6 位数字

新建保险箱、修改密码、重置密码时，新密码只要求 **正好 6 位数字**（例如 `246810`），不再要求大小写字母。
密码框只能输数字。旧版本建的保险箱如果还是原来的复杂密码，照样能解锁。

## 忘记密码：3 个密保问题，答对任意一个即可

- 新建保险箱时不再显示恢复密钥，改为从预设里选 **3 个不重复的密保问题** 并填答案
  （我的生日、我出生的城市、父亲 / 母亲 / 配偶的生日、父亲 / 母亲出生的城市、小学、小名、第一只宠物的名字）。
  每新建一个保险箱都要设一次。
- 解锁时点「忘记密码？」→ 回答密保（会的填，不会的空着）→ 答对一个就解锁，之后可以顺手设新密码。
- 「•••」菜单：「忘记密码…」改为答密保 + 设新密码；「换新恢复密钥…」改为「修改密保问题…」（要输当前密码）。
- 答案不分大小写，忽略空格和标点；生日 `1998-03-12` / `1998/3/12` / `1998年3月12日` / `19980312` 等价；城市带不带「市」都行。
- 答错和输错密码一样计次：连续错 5 次后每次要等 10–60 秒。
- 命令行：`create` 会问密保；`unlock / lock / verify / recover --forgot` 用密保；`reset-password` 答密保；新增 `set-questions`。

## 兼容旧保险箱

- 0.5.x 及以前建的保险箱：仍可用原密码和恢复密钥，格式不变，旧版软件也能继续打开。
- 在「••• → 设置密保问题…」补设密保后，该保险箱升级为新格式（版本 2），原恢复密钥作废，旧版软件会提示升级。

## 安全提醒

6 位数字只有一百万种组合，生日、城市这类答案也容易被查到。输错等待只能挡住守在电脑前乱试的人，
挡不住把整个保险箱拷走后离线慢慢试的人。保险箱文件夹不要放在别人能随手拷走的地方，密保尽量选组外人查不到答案的问题。

## 验证

186 个自动化测试、23 项 GUI 自检、默认参数验收 7 项（含「只答对一个密保问题即可解锁」）全部通过。
