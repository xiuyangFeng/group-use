# 常见问题与报错对照表

> 先按这张表处理；解决不了再收集日志发给维护者（见最后一节）。
> 处理任何问题前，**不要删除或手工修改 `.vault/` 里的任何文件**——那可能让本来能恢复的数据变成不能恢复。

## 1. 安装 / 启动

| 现象 | 原因 | 处理 |
|---|---|---|
| macOS 提示“无法打开，因为 Apple 无法验证此 App 是否包含恶意软件” | 安装包未签名（预算内不买证书） | 右键 App → 打开 → 再点“打开”；或 `系统设置 → 隐私与安全性` 里点“仍要打开” |
| Windows 蓝色 SmartScreen“Windows 已保护你的电脑” | 同上，未签名 | 点“更多信息”→“仍要运行” |
| Windows 双击后没反应/闪退 | 被 360/火绒/杀软拦截，或缺 VC++ 运行库 | 看杀软隔离区恢复；装微软 VC++ 2015–2022 运行库；仍不行用 PowerShell 运行 exe 看报错 |
| 双击 `.command` 提示“无法打开，来自身份不明的开发者” | macOS 对脚本的隔离 | 右键“打开”，或 `系统设置 → 隐私与安全性 → 仍要打开` |
| 右键菜单里没有“用文件保险箱上锁” | 快速操作未安装/访达没刷新/扩展被关 | 双击 `安装快速操作.command`；访达重启；`系统设置 → 隐私与安全性 → 扩展 → 访达` 勾选 |
| 同一时间只能开一个实例，再双击没反应 | 单实例锁（防止两个进程同时改同一个库） | 从菜单栏/托盘打开已有窗口；确实要重启用托盘“退出” |
| 托盘/菜单栏图标不见了 | 系统隐藏了图标，或设置里关了“最小化到托盘” | 看菜单栏折叠区；设置里重新打开；重启程序 |

## 2. 密码 / 恢复密钥

| 现象（原文） | 原因 | 处理 |
|---|---|---|
| `密码不对` | 输错/大小写/输入法全角 | 慢慢重输；确认大写锁定；连续错 5 次后会有延迟，属正常 |
| 连续输错后“要等几秒” | 防暴力：第 6 次起延迟（10 秒起，最多 60 秒） | 等提示的时间再试；别反复点 |
| `恢复密钥不对` | 少输/多输字符、把 `-` 看成下划线 | 恢复密钥只含 `A–Z 2–7` 和分组横线，横线可忽略；重新抄一遍 |
| 忘记密码、恢复密钥也丢了 | 加密设计上无法找回 | 只能放弃该保险箱；这正是“没密码绝对打不开”的代价。重要数据请留锁好的备份 |
| `密码不符合要求：至少 8 位、包含数字…` | 密码没同时满足长度/数字/大写/小写 | 按界面实时勾选补齐；组内共用密码建议再长一点 |

## 3. 上锁 / 解锁报错

| 现象（原文） | 原因 | 处理 |
|---|---|---|
| `「CT 数据脱敏工具」（14:05 开始…）正在使用这个保险箱里的文件，现在不能上锁` | 脱敏工具正在读这个保险箱里的原始数据/写映射表 | 等脱敏完成，或在脱敏工具里点「停止」再上锁。脱敏工具被强制关掉的话，3 分钟后自动解除 |
| `「xx」正在被其他程序使用，现在不能上锁` | 文件被 Excel/Word/预览/看图软件占用 | 关掉对应软件再点“上锁”（不用重新输密码）；也可以选“留在后台”，关完软件后点“全部上锁” |
| `文件「xx」删不掉，可能正被其他程序占用` | 扫描后、删除前又被占用 | 同上；此时保险箱处于可恢复的中间状态，**不会丢数据** |
| `这个保险箱目前已经锁着` / `这个保险箱已经解锁了` | 重复操作 | 刷新界面；按当前状态操作即可 |
| `上次操作没有完成（状态 LOCKING/UNLOCKING…），需要先恢复` | 上次上锁/解锁中途断电、强杀、崩溃 | 重新打开程序 → 点“恢复”→ 选“继续”或“回滚到已上锁”；恢复可以再来一次 |
| `磁盘空间不够：需要约 X，实际只剩 Y` | 空间不足（峰值约 2×最大单文件 + 32 MiB） | 挪走其它大文件/清废纸篓；把大文件夹拆成两个保险箱；重试 |
| `manifest.db 丢失…请从备份恢复，不要继续操作` | 元数据被删/盘损坏 | 停止操作，从备份恢复整个文件夹；不要尝试手工改 `.vault` |
| `缺少密文文件…保险箱可能被外部改动过` | 有人删/移了 `blobs` 里的文件，或同步软件冲突 | 从备份/同步历史恢复缺失文件；不要重新上锁 |
| `文件「xx」的密文损坏，且明文已不在` | 盘坏/同步截断/手工改过 | 从备份恢复该文件；其它文件一般还能解锁 |
| `这个文件夹已经是保险箱了` | 选了一个已经建过库的文件夹 | 直接解锁；或换一个空文件夹新建 |
| `文件夹里有 .vault 但缺少 header.json…` | 上次创建没完成/被杀软删了 header | **先整体备份**，再联系维护者；不要直接删 `.vault` |
| `不是保险箱：找不到 .vault/header.json` | 文件夹没建库，或 `.vault` 被改名/移动 | 确认路径；从备份恢复 |
| `这个保险箱是更新版本的软件创建的，请升级软件` | 新版本格式，旧程序打不开 | 换用较新安装包；不要用旧版继续写 |
| `路径「xx」的类型和记录不一致` | 解锁期间把一个文件换成了同名文件夹（或反之） | 先备份；把类型改回去再上锁；不行就联系维护者 |

## 4. 数据安全（最重要）

| 情况 | 正确做法 |
|---|---|
| 上锁/解锁到一半断电、死机、被强杀 | 重新打开 → 点“恢复”。恢复幂等、可再中断；**不要手工删 `.vault`** |
| 想重装系统/换电脑 | 先在上锁状态把整个文件夹（含 `.vault`）复制走；到新机器解压后用密码解锁即可。也可以用程序里的“导出/备份”说明 |
| 误删了解锁状态下的文件 | 直接从备份恢复；保险箱本身无法恢复被删的明文（删除是同步的） |
| 磁盘快满了 | 先别操作；按第 3 节“空间不够”处理；强行操作可能损坏 |
| 文件夹放在 OneDrive/iCloud/坚果云同步目录 | 同步软件可能在写入中途抓文件，造成冲突；建议放**本地非同步目录**，或暂停同步后再上锁/解锁 |
| 有人删掉了整个 `.vault` | 上锁状态下普通操作删不掉（系统级锁定）；解锁期间、或管理员硬删、或放在 U 盘/网络盘上时仍可能被删，只能从备份恢复。重要数据请另留一份锁好的备份 |
| 上锁后移动/删除文件夹提示「已锁定」「Operation not permitted」「需要权限」 | 正常：上锁后防移动/删除。要搬家先解锁，挪好后把新位置拖进窗口再上锁 |
| 担心审计日志被别人改 | 审计是“半弱审计”：哈希链能发现改行，但挡不住管理员删整个文件；重要操作请配合备份留痕 |
| 第二个人用同一个系统账户 | 无法区分“谁”操作的；请每人一个系统账户（验收第 13 条） |

## 5. 审计 / 设置 / 日志

| 现象 | 原因 | 处理 |
|---|---|---|
| 审计窗口打不开/为空 | 数据目录权限问题，或从没操作过 | 看 `%APPDATA%\文件保险箱\`（Win）/ `~/Library/Application Support/文件保险箱/`（mac）是否可写 |
| 导出 CSV 用 Excel 打开乱码 | 旧版导出编码不对 | 0.3.0 已带 UTF-8 BOM；若仍乱码，用 Excel“数据→从文本”选 UTF-8 |
| 审计校验报“链断了” | 日志被改动/损坏 | 以具体报错行号为准；需要时从备份恢复日志；不影响保险箱本体 |
| 设置里改了自动上锁没生效 | 只对已解锁的库生效；改完要保存 | 重新打开设置确认；解锁状态下看主界面倒计时 |
| 找不到日志 | 路径见下 | macOS：`~/Library/Application Support/文件保险箱/gui.log`；Windows：`%APPDATA%\文件保险箱\gui.log` |

## 6. 怎么反馈问题

1. 先跑诊断包（不含密码/恢复密钥/文件内容，但可能含路径和账户名，发前看一眼）：

   - macOS：`"/Applications/文件保险箱.app/Contents/MacOS/文件保险箱" --diagnostics --out ~/Desktop`
   - Windows：`文件保险箱.exe --diagnostics --out %USERPROFILE%\Desktop`

2. 附上：`--version` 输出、问题截图、复现步骤、是否丢数据、诊断 zip；
3. 如果涉及“打不开/恢复失败”，**先保留现场**（别删 `.vault`、别重装覆盖），再联系维护者；
4. Windows 还可附 `installers\windows\验收自检.ps1` 生成的 `验收结果.txt`。
