# 仓库迁移说明（group-use）

- 日期：2026-11-01
- 结论：原来分开的“文件保险箱”和“CT 脱敏”两个项目，已经合并到组内私有仓库
  <https://github.com/xiuyangFeng/group-use>，一个仓库两个子目录；历史能保留的都保留了。

## 1. 为什么合并

组里只有 2–5 个人用，两个工具都是一次性做完、偶尔改。分两个仓库要分别记 CI、发安装包、
加协作者；合成一个私有仓库后：

- 同事只需要一个地址，下载一个 Releases 页面；
- 两个项目的改动互不影响（CI 按子目录路径过滤，见第 4 节）；
- 患者数据、密码、恢复密钥仍然都不进仓库（安全约定见仓库根 README）。

## 2. 现在的结构

```
group-use/
├─ README.md                     仓库总说明 + 安装包下载
├─ .github/workflows/
│  ├─ build-vault.yml            文件保险箱：macOS + Windows 测试/自检/打包
│  └─ build-deid-windows.yml     CT 脱敏：Windows exe 构建 + 自检
├─ 文件保险箱/                    加密工具（原项目目录）
└─ 脱敏小软件/                    CT 脱敏（原 CT_Deid 仓库全部文件）
```

## 3. 历史是怎么保留的

| 项目 | 处理 | 结果 |
|---|---|---|
| CT 脱敏（原 `CT_Deid`） | 用 `git mv` 把原仓库文件整体移进 `脱敏小软件/`，保留原提交历史 | 原 `CT_Deid` 的提交（包括 `55af01b`）现在都在 `group-use` 的 `脱敏小软件/` 路径历史里；`git log --oneline -- 脱敏小软件` 能看到 |
| 文件保险箱 | 原目录当时还没建 git 历史；按当前源码树一次性提交进 `文件保险箱/`（135 个文件） | 从 M1 到 M3 的代码/文档都在仓库里；后续每步修改都有提交 |
| 两个项目各自的 `.git` | 没有嵌套进新仓库（`.git` 不提交）；本地 `脱敏小软件/.git` 仍然保留作为备份 | 不影响新仓库；旧仓库删除后本地副本仍可查看旧历史 |

## 4. CI 怎么触发

两个流程都配置了 `paths` 过滤和手动触发：

- 改 `文件保险箱/**` → 只跑 `build-vault.yml`：macos-14 + windows-latest 矩阵，
  136 个 pytest、GUI 18 项自检、退出自动上锁、`--acceptance` 6 项、PyInstaller 打包、
  zip 解压后自检 + 文件夹参数冒烟、上传安装包；
- 改 `脱敏小软件/**` → 只跑 `build-deid-windows.yml`：Windows 上跑 pytest、PyInstaller
  打成单文件 exe、exe 冒烟、上传 `CT_Deid_Windows.zip`；
- 两个流程都可以在 Actions 页面点 “Run workflow” 手动跑。

最近一次双平台全绿：[run 41287725017](https://github.com/xiuyangFeng/group-use/actions/runs/41287725017)。

## 5. 安装包去哪下

<https://github.com/xiuyangFeng/group-use/releases/tag/v0.3.1>

里面同时放了文件保险箱（macOS dmg/zip、Windows zip、源码包）和 CT 脱敏（Windows exe）。
文件名用 ASCII `fdvault` 代替“文件保险箱”，避免中文文件名在部分浏览器/解压工具里乱码；
解压出来的程序名仍然是中文。每个文件都可以用 `SHA256SUMS.txt` 校验。

## 6. 旧仓库清除情况

- `xiuyangFeng/CT_Deid`：**已由用户删除**（2026-11-01）；原文件和历史都已在新仓库里。
- `xiuyangFeng/fdvault-ci`：验证 CI 时临时建的测试仓库，**仍存在**；当前 `gh` token 没有
  `delete_repo` 权限，需要管理员删除：

```bash
gh auth refresh -h github.com -s delete_repo
gh repo delete xiuyangFeng/fdvault-ci --yes
```

也可以网页：仓库 `fdvault-ci` → Settings → Danger Zone → Delete this repository。

迁移后的确认（在新仓库里执行）：

```bash
git clone https://github.com/xiuyangFeng/group-use.git
cd group-use
git log --oneline | grep 55af01b
# 应输出：55af01b Mac 压缩包去掉 AppleDouble 隐藏文件

git log --follow --oneline -- 脱敏小软件/README.md | head
```

本地 `脱敏小软件/` 目录如果还要继续改，建议以后直接在 `group-use` 仓库的
`脱敏小软件/` 子目录里改；本地旧 `.git` 的 `origin`（`CT_Deid`）已经失效，
可以留作离线备份，也可以把 remote 改成新仓库。
