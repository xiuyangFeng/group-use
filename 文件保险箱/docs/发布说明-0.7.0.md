# 文件保险箱 0.7.0 发布说明

- 发布日期：2026-11-08
- 在 0.6.1（见 [发布说明-0.6.1](发布说明-0.6.1.md)）基础上：加解密改用 C++、新增闪电锁、上锁更快、新建时可以取消

## 闪电锁（不加密，1 秒左右锁上 / 打开）

新建保险箱时在「设置 6 位数字密码」这一页选上锁方式，**默认是闪电锁**：

- 文件再大也是 1 秒左右：实测 107 GB + 2 万个文件，首次上锁 0.2 秒、解锁 0.3 秒、上锁 0.4 秒；
- 和加密保险箱用同一套密码 / 密保，同样防移动、防删除，主窗口卡片上写「闪电锁（不加密）」；
- **不加密**：文件只是挪进 `.vault` 藏起来并禁止访问，只防同一台电脑上随手翻看；硬盘被拆走、换个系统、
  或者有人用管理员权限，仍能看到内容。**患者资料等敏感数据请选「加密」**；
- 中途断电点「恢复」即可；解锁时原位置已有同名的东西，不覆盖，挪回来的那份改名「（闪电锁恢复 1）」。

## 加密更快（C++ 引擎）

- 加解密改用 C++ 重写，用满全部 CPU 核心（Apple 芯片 NEON / SHA2 指令，Intel / AMD 的 AVX2 / SHA-NI 指令），
  文件格式不变，旧保险箱照常打开；
- **上锁几乎瞬间**：解锁时保留一份密文，上锁时没改过的文件直接用它，只重新加密改过的。
  例：4 个 500 MB 文件从 1.7 秒降到 0.2 秒，2000 个 1 MB 文件从 3.5 秒降到 0.35 秒；
- 代价：解锁期间文件夹大约占两倍空间（上锁后释放）；磁盘不够时自动用老办法，只是上锁慢一些；
- 解锁仍受硬盘写入速度限制（2 GB 约 2–5 秒）。

## 其它

- **新建时可以取消**：加密中途点「取消」（或关掉向导），已经加密的文件会还原，文件夹变回原样；
- **Windows 上锁后不能移动文件夹**：程序开着时，已上锁的文件夹拖不走、改不了名（U 盘、磁盘根目录也一样）；
- 新建向导里「组内共用密码」改为「密码」。

## 验证

289 个自动化测试、27 项 GUI 自检、Windows CI（含打包后验收 8 项）全部通过。新增的检查：

- C++ 引擎和原来的 Python 实现逐字节一致，SIMD 实现和通用实现交叉比对，启动时自检；
- 增量上锁：内容改了、大小没变、修改时间还被改回原样，也能识别并重新加密；
- 闪电锁 6 个断电点、取消、文件被占用、重名、密码错误；取消新建在每个取消点都能还原；
- 30 轮随机杀进程压力测试（58 次断电）0 处不一致。
