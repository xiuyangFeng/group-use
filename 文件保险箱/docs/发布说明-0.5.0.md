# 文件保险箱 0.5.0 发布说明

- 发布日期：2026-11-05
- 安装包：本机 `dist/` 下的 `文件保险箱-0.5.0-macOS-arm64.zip` / `.dmg`、源码包（sha256 见 `dist/SHA256SUMS.txt`）
- Windows：代码已支持，**未在 Windows 真机 / CI 上跑过**，发给 Windows 同事前要先跑一遍 CI 和真机验收

## 新功能：上锁后不能移动、删除

上锁完成后，保险箱文件夹（根目录、`如何解锁.txt`、整个 `.vault/`）被系统锁定：

| 平台 | 做法 | 效果 |
|---|---|---|
| macOS | 每个条目加「锁定」标记（`uchg`）+ 目录加 ACL `everyone deny delete,delete_child` | 访达显示「已锁定」；拖走、改名、删除、改写都被拒绝（`Operation not permitted`）；访达里点「仍要移到废纸篓」后还要输管理员密码 |
| Windows | 根目录加可继承的拒绝规则：Everyone 不能删除（DE）/ 删除子项（DC） | 资源管理器移动、删除提示「需要权限」；`.vault` 里每个文件都继承，不会删一半 |

- 解锁、改密码、换恢复密钥、校验时，程序拿到保险箱互斥锁后先撤掉保护，结束时如果还是「已上锁」再加回去（密码输错也会加回去）；
- 旧版本上锁的保险箱：打开软件（列表刷新）或运行 `cli status` 时自动补上；
- `cli status` 多一行「防移动/删除：已开启 / 未开启」；
- exFAT U 盘、网络盘等不支持这些属性的磁盘上加不上，上锁照常完成，只是不防删；
- 电脑管理员仍然可以硬删（这是操作系统的边界），所以「另留一份锁好的备份」的建议不变；
- 要搬家：先解锁 → 挪文件夹 → 把新位置拖进窗口 → 上锁。复制不受影响。

## 其它改动

- 测试和自检不再往真实的审计日志 / 设置里写记录：新增环境变量 `FDVAULT_DATA_DIR`（测试夹具和 GUI 自检脚本自动设置）；
- 打包版 `--selftest` 和 `--acceptance` 各多一项「上锁后不能移动 / 删除」，结束时撤掉临时保险箱的保护，临时目录能被系统清理；
- 自检 / 压力测试脚本在系统临时目录里造保险箱时设 `FDVAULT_NO_PROTECT=1`，不留删不掉的临时文件；
- 包含 0.4.1 的改动：外部程序（CT 脱敏工具）声明「正在使用」时不能上锁、不自动上锁。

## 兼容性

加密格式不变（`fdv1`）。0.5.0 能直接打开旧版本的保险箱；旧版本打开 0.5.0 上锁的保险箱时，
因为旧版不会撤保护，解锁会失败（报权限错误、不会丢数据）——请所有人一起升级。
