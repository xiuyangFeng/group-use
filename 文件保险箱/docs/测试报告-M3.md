### Windows CI 适配记录（本轮修复）

| 问题 | 处理 |
|---|---|
| cp1252 控制台输出 `✔/中文` 时 `UnicodeEncodeError` | `core/console.py` 的 `setup_utf8_stdio()` 统一把 stdout/stderr 设为 UTF-8；测试/脚本子进程统一 `encoding="utf-8", errors="replace"` |
| 自检/验收/彩排的 `_digest` 用 `/` 跳过 `.vault`，Windows 上分隔符是 `\` → 摘要不一致 | 改用 `Path.as_posix()` 统一分隔符 |
| 单个进程里造两个 `SingleInstance` 时 Windows 命名管道 `readyRead` 不触发 | 连接一建立就唤起已有窗口；另加 `scripts/gui_two_instance.py` 用真实两进程验证（Windows 0.4s 退出，PASS） |
| 创建过 Qt 组件后进程退出时 `os._exit` 偶发 access violation（3221225477）/ stack overflow（0xC0000409）→ 已通过的检查被当成失败 | 新增 `core/console.py::hard_exit()`：Windows 用 `TerminateProcess(GetCurrentProcess(), code)` 绕过 DLL detach；自检、无界面模式、退出上锁检查统一走它 |

已知风险：Windows 上 PyInstaller 的 Qt 插件、中文 exe 名、杀毒软件误报，都需要真机确认。
如果杀毒软件误报，加白名单即可（未签名程序的常见问题）。
