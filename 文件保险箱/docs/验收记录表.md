## 4. 手工验收步骤（逐条打勾并记结果）

1. ☐ 上锁后用记事本/VSCode 打开 `.vault/blobs` 文件 → 乱码；搜不到原文件名。
2. ☐ 解锁后与备份对比 2 个文件的 SHA256/修改时间 → 一致。
3. ☐ 上锁到一半强制结束进程 → 重新打开 → 恢复 → 文件完整。
4. ☐ 连续输错 6 次密码 → 第 6 次明显等待。
5. ☐ 用恢复密钥解锁 → 重设密码 → 旧密码失效。
6. ☐ 做一次加密操作 → 审计记录出现 → 导出 CSV → 手工改一行 → 校验报错。
7. ☐ 把磁盘塞到 <10% 剩余 → 试上锁/解锁 → 看提示是否清楚。
8. ☐ 建含 emoji、超长文件名、空文件夹的保险箱 → 解锁后逐个打开。
9. ☐ 用 Excel 打开保险箱里的表格不关 → 点上锁 → 中止并提示；关 Excel → 成功。
10. ☐ 拿约 10 GB / 1 万文件 → 计时上锁+解锁 → < 5 分钟。
11. ☐ 解锁后退出程序 → 观察自动上锁；重新打开看"上次没上锁"提示。
12. ☐ 跑 100 次循环脚本，同时用 Everything/`grep -r` 搜敏感字符串 → 0 命中。
13. ☐ 建第二个系统账户 → 登录后访问另一个账户的保险箱 → 无权访问/看不到明文。
14. ☐ macOS：双击 `安装快速操作.command` → 右键文件夹 → 快速操作 → 用文件保险箱上锁。
