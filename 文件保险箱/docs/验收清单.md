## 手动验收步骤（打印出来打勾用）

1. ☐ **看密文**：上锁后打开 `.vault/blobs` 里的文件，用记事本/VSCode 打开是乱码；搜索不到原文件名。
2. ☐ **看还原**：解锁后逐个文件与备份对比 SHA256（或直接打开看一眼）。
3. ☐ **断电**：上锁到一半强制关机/任务管理器结束进程，重启后按提示恢复，文件完整。
4. ☐ **错密码**：连续输错 6 次，确认第 6 次开始明显等待。
5. ☐ **恢复密钥**：故意输错密码，用恢复密钥解锁 → 重设密码 → 旧密码失效。
6. ☐ **审计**：做一次解锁/上锁，看审计记录；导出 CSV；改一行再点"防篡改校验"，应报错。
7. ☐ **磁盘**：把磁盘塞到只剩不到 10%，做一个小保险箱的上锁/解锁，观察提示。
8. ☐ **怪名字**：建一个含 emoji、超长文件名、空文件夹的保险箱，解锁后逐个打开。
9. ☐ **文件占用**：用 Excel 打开保险箱里的表格不关，点上锁 → 应中止并提示；关掉 Excel 再点 → 成功。
10. ☐ **性能**：拿一个约 10 GB / 1 万文件的文件夹，计时上锁+解锁，应 <5 分钟。
11. ☐ **退出**：解锁后直接退出程序，观察是否自动上锁；重新打开看"上次没上锁"提示。
12. ☐ **100 次**：跑 `scripts/stress_cycles.py`，同时用 Everything/`grep -r` 搜敏感字符串。
13. ☐ **多账户**：建一个测试 Windows 账户，登录后访问另一个账户的保险箱文件夹，应无权访问/看不到明文。
14. ☐ **macOS 快速操作**（M4）：双击 `installers/macos/安装快速操作.command`，右键文件夹 →
    快速操作 → 用文件保险箱上锁，应打开程序并预填该文件夹。

## 已知未覆盖项（会写进使用说明，不隐瞒）

- macOS 菜单栏图标、托盘菜单的**系统级外观**没有肉眼确认（离屏渲染看不到菜单栏）；
- 真实自动上锁 15 分钟流程没坐着等过（逻辑用模拟空闲验证）；
- Windows 全套（打包、SmartScreen、右键菜单、Excel 占用、路径边界）需要那台共用 Windows 电脑；
- 安装包未签名（预算内不签），首次打开需要手动放行；
- 多系统账户隔离需要管理员权限建测试账户。
