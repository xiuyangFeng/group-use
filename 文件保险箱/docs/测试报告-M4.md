## 3. 为什么还没做真实数据试点

1. 试点对象是**脱敏患者/伦理数据**，需要用户选目录、确认脱敏，不能由代理自己拿数据；
2. Windows 真机（组里共用电脑）上的打包、SmartScreen、Excel 占用、路径边界必须在那台机器上跑；
3. 产品最终名字未定（现在是工作名"文件保险箱"）。

## 4. 复现命令

```bash
cd 文件保险箱
.venv/bin/python -m pytest tests -q                    # 136 个测试（跳过 3 项 Windows 专用）
.venv/bin/python scripts/gui_selftest.py                # 18 项
FDVAULT_KDF_FAST=1 .venv/bin/python scripts/stress_cycles.py --cycles 100
.venv/bin/python scripts/build_app.py                   # zip + dmg + 源码包 + SHA256SUMS
```

Windows（真机）：

```powershell
.venv\Scripts\python -m pytest tests -q
.venv\Scripts\python scripts\gui_selftest.py
.venv\Scripts\python scripts\build_app.py
# 解压后右键"使用 PowerShell 运行" installers\windows\安装右键菜单.ps1
```
