# 文件保险箱 0.5.1 发布说明

- 发布日期：2026-11-05
- 在 0.5.0（上锁后防移动 / 删除，见 [发布说明-0.5.0](发布说明-0.5.0.md)）基础上修了两个问题、改进了 Windows 包

## 修复：⌘Q / Dock 退出 / 注销 / 关机不上锁

以前只有托盘菜单的「退出」会先把开着的保险箱锁回去。macOS 上按 ⌘Q、Dock 右键「退出」、
注销、关机走的是系统的退出请求（`NSApp terminate:` → Qt 给程序发 `QEvent.Quit`），
程序直接退出，保险箱一直是解锁状态（明文留在硬盘上）。

现在 `gui/app.py` 的 `QuitGuard` 把系统退出请求拦下来，先走和托盘「退出」同一套
「退出前上锁」流程；锁不上（文件被占用等）时问用户，选「取消 / 留在后台」就拒绝这次退出。
Windows 注销 / 关机（`commitDataRequest`）也先上锁，锁不上就请求取消关机。

验证：`scripts/gui_exit_lock.py` 新增系统退出请求的两个场景（锁不上 → 拒绝退出；正常 → 先上锁再退出）；
另外用真实 Cocoa 窗口系统调 `NSApp terminate:` 实测：旧逻辑退出后仍是「已解锁」，新逻辑退出前已上锁。

注意：「上次没锁回」的保险箱（不在本次程序的会话里，程序手里没有密钥）退出时锁不了，
需要打开软件输密码上锁——这一点和以前一样。

## 修复：Windows 上的 PowerShell 脚本中文乱码

`安装右键菜单.ps1`、`卸载右键菜单.ps1`、`验收自检.ps1` 没有 UTF-8 BOM。Windows 自带的
PowerShell 5.1 会按系统编码（中文系统是 GBK）读，脚本里的「文件保险箱.exe」等中文会变乱码，
找不到程序。现在都加了 BOM，并加了测试防止再丢。

## 改进：Windows 包解压即用

Windows 压缩包本来就自带运行环境（PyInstaller 打包：Python、Qt、加密库都在 `文件保险箱\_internal\`），
**不需要安装 Python 或任何依赖**。现在压缩包里还一起放了：

- `先看我.txt`：三步用起来；
- `安装说明.md`、`安装右键菜单.ps1`、`卸载右键菜单.ps1`、`验收自检.ps1`。

`run_from_source.bat` / `build_windows.bat` 标注为开发者用（这两个才需要 Python）。
