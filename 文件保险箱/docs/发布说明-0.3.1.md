## 这个版本能做什么

- 把一个文件夹原地加密上锁：锁上后只剩 `.vault/` 密文和 `如何解锁.txt`，文件名也加密；
- 输密码原地解锁，用完一键锁回；15 分钟无操作自动上锁；关窗口缩到菜单栏/托盘；
- 忘记密码可用 32 位恢复密钥解锁并重设密码；旧密码立即失效；
- 审计日志（哈希链，可筛选/导出 CSV/校验篡改），记录哪个系统账户做了什么；
- 断电解锁/上锁可恢复，恢复本身可再中断；120 次强制杀进程测试 0 字节丢失；
- 文件被 Excel 等占用时上锁前中止并提示；密码连错 5 次后加延迟；
- 中文界面，不联网、无遥测（静态检查 + 无网络代码）；
- macOS 支持拖文件夹到图标、`open -a`、Finder 快速操作；Windows 支持右键菜单（`%1`）。

## 安全设计要点

| 关注点 | 做法 |
|---|---|
| 先删后写？ | 永远先写新副本并 fsync，确认后才删旧副本；断电最坏是两份都在，恢复时清理 |
| 断电恢复 | 状态机 LOCKED/UNLOCKING/UNLOCKED/LOCKING/INCONSISTENT + 每文件子状态；manifest 为权威；恢复幂等可再中断 |
| 密码 | Argon2id（64 MiB / t=3 / p=1），参数存 header；密码和恢复密钥都不落盘 |
| 加密 | ChaCha20-Poly1305 分块，AAD 绑定 uuid/块号/是否末块，防重排/截断/拼接 |
| 文件名 | 单独 HKDF 子密钥 AEAD 加密进 SQLite，`.vault` 里没有明文路径 |
| 审计 | JSONL + SHA-256 哈希链；记录系统账户、时间、动作、结果 |
| 磁盘峰值 | 2×最大单文件 + 32 MiB 预留，开始前检查，不够直接拒绝 |

## 已知限制（接受）

- 解锁期间是明文，Spotlight/缩略图/云同步可能读到；用完请锁回；
- 安装包未签名（预算内不买证书），首次打开要手动放行；
- 审计是"半弱"审计：能发现改日志，挡不住管理员删整个日志；
- 加密防偷看、不防删；重要数据请另留一份锁好的备份；
- 保险箱 ≤ 20 GB、单文件 < 1 GB（设计目标）；符号链接/特殊文件跳过；
- 每人一个系统账户；同一账户多人共用无法区分"谁"。

- 136 个自动化测试（核心/CLI/GUI/打包/安装包/CI 静态检查），macOS 本机跳过 3 项 Windows 专用；
