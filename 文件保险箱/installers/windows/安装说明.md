# Windows 安装与首次使用

## 1. 解压

把 `文件保险箱-x.y.z-Windows-x64.zip` 解压到一个固定位置，例如：

```
D:\工具\文件保险箱\
├── 文件保险箱.exe
├── _internal\          ← 不要动这个文件夹
└── ...
```

> 建议放在**本机固定磁盘**，不要放在 U 盘或网络盘里（程序路径一变，右键菜单和配置会失效）。

## 2. 第一次打开（SmartScreen 提示）

安装包没有花钱买代码签名，Windows 会弹：

> Windows 已保护你的电脑

点 **“更多信息” → “仍要运行”** 即可。只需要第一次这样点。
（签名要每年付费；组内自用、从内网共享盘拿安装包时这样做是可以接受的。）

## 3. 加右键菜单（推荐）

右键 `安装右键菜单.ps1` → **“使用 PowerShell 运行”**。
之后在资源管理器里：

- Windows 11：右键文件夹 → **显示更多选项** → **用文件保险箱上锁**
- Windows 10：右键文件夹 → **用文件保险箱上锁**

不需要时可以运行 `卸载右键菜单.ps1` 移除。
菜单只写当前用户（`HKCU`），不需要管理员权限，也不会影响别的账户。

## 4. 一键验收自检（建议装完先跑）

右键 `验收自检.ps1` → **“使用 PowerShell 运行”**。它会自动：

1. 找到 `文件保险箱.exe`；
2. 跑打包自检 `--selftest`（验证加密核心 + 界面组件，约 10 秒）；
3. 检查右键菜单是否装好、数据目录是否可写；
4. 列出仍需手工点的 7 步（Excel 占用、退出自动上锁、多账户等），结果写到同目录 `验收结果.txt`。

没有“失败”项、手工步骤过一遍，就可以放心建正式保险箱了。

## 5. 首次建保险箱

1. 双击 `文件保险箱.exe`（或右键文件夹选菜单）；
2. 点 **新建保险箱** → 选一个敏感数据文件夹（**先备份！**）；
3. 设组内共用密码（≥12 位，规则写在界面上）；
4. **抄下恢复密钥**：32 位，分 8 组；这是唯一一把，程序不保存；
5. 等首次上锁进度条走完；文件夹里只剩 `.vault\` 和 `如何解锁.txt`。

建议组内约定：

- 密码写在只有组内可见的地方（或当面告知）；
- 恢复密钥打印一份放导师抽屉，和密码分开存放；
- 每个保险箱 ≤ 20 GB，单文件 < 1 GB；
- 重要数据在保险箱**之外**再留一份锁好的备份（加密不防删）。

## 6. 日常使用

- 双击程序 → 保险箱卡片 → **解锁** → 输密码 → 文件夹变成普通文件夹，可以正常打开/编辑；
- 用完点 **立即上锁**，或等 15 分钟自动上锁（设置里可改）；
- 关窗口默认缩到右下角托盘；托盘右键有 **立即上锁全部**；
- **审计日志** 能看谁在什么时候解锁/上锁，能导出 CSV；
- 电脑要重装/换人前，先 `立即上锁全部`，再备份锁好的保险箱文件夹。

## 7. 数据位置

| 内容 | 位置 |
|---|---|
| 保险箱本身 | 你选的那个文件夹里（`.vault\`） |
| 界面配置 | `C:\Users\<你>\AppData\Roaming\组内工具\文件保险箱\` |
| 审计日志 | 同上目录 `audit.jsonl` |
| 程序日志 | 同上目录 `gui.log` |

配置和审计日志**不在保险箱里**，删除不影响解密；但审计记录会丢。重装系统前可以备份这个目录。

## 8. 遇到问题

| 现象 | 处理 |
|---|---|
| 打不开、闪退 | 看 `%APPDATA%\组内工具\文件保险箱\gui.log` 最后几行 |
| 提示“另一个窗口正在操作” | 等另一个窗口结束；必要时关掉另一份程序（任务管理器结束 `文件保险箱.exe`） |
| 解锁中断/断电 | 重新打开程序，会弹恢复向导，选“继续”或“回滚到已上锁” |
| 忘了密码 | 用恢复密钥重置（主界面 → 详情/恢复）；恢复密钥也丢了就**无法恢复** |
| 磁盘不够 | 上锁/解锁峰值需要额外“最大单文件 + 32 MiB”，先清一点空间 |

## 9. 卸载

1. 先把所有保险箱**上锁**；
2. 删除程序文件夹；
3. 如需要，删除 `%APPDATA%\组内工具\文件保险箱\`；
4. 运行 `卸载右键菜单.ps1`（如果装过）。

保险箱文件夹里的 `.vault\` 不要删——那是你的数据。删掉就真的没了。
