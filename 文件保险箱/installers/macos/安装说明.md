# macOS 安装与首次使用

## 1. 解压与安装

把 `文件保险箱-x.y.z-macOS-arm64.zip` 解压，得到 `文件保险箱.app`，
拖到 **“应用程序”** 文件夹（或放桌面也行）。

> 只支持 Apple 芯片（M1/M2/M3/M4）的 Mac。Intel Mac 需要另打 x86_64 包。
> 当前包**没有签名/公证**，所以第一次打开会被 Gatekeeper 拦。

## 2. 第一次打开（Gatekeeper 提示）

在“应用程序”里 **右键 `文件保险箱.app` → 打开 → 再点“打开”**。
之后双击就能正常启动。
（如果提示“已损坏，无法打开”，在终端执行：`xattr -dr com.apple.quarantine /Applications/文件保险箱.app`）

## 3. 首次建保险箱

1. 双击打开，点 **新建保险箱**；
2. 选一个敏感数据文件夹（**先备份！**）；
3. 设密码（6 位数字）；
4. **抄下恢复密钥**：32 位，分 8 组；这是唯一一把，程序不保存；
5. 等首次上锁进度条走完；文件夹里只剩 `.vault/` 和 `如何解锁.txt`。

## 4. 日常使用

- 解锁后文件夹变成普通文件夹，Finder 里正常打开/编辑；
- 用完点 **立即上锁**，或等 15 分钟自动上锁；
- 关窗口缩到菜单栏，菜单栏图标右键有 **立即上锁全部**；
- **审计日志** 支持筛选、导出 CSV、校验哈希链；
- 建议把保险箱文件夹从 Spotlight / iCloud 同步中排除（解锁期间系统索引可能读到明文）；
- 重要数据在保险箱**之外**再留一份锁好的备份。

## 5. 加“快速操作”右键菜单（可选，M4）

**推荐：双击安装**

1. 先确认 `文件保险箱.app` 在「应用程序」里（快速操作靠名字找程序）；
2. 双击 `installers/macos/安装快速操作.command`；
   - 如果提示"无法打开，因为无法验证开发者"：右键这个 `.command` → 打开；
3. 之后右键任意文件夹 → **快速操作** → **用文件保险箱上锁**，
   程序会自动打开并把该文件夹填进新建向导。

**卸载**：双击同目录的 `卸载快速操作.command`，或在访达里删除
`~/Library/Services/用文件保险箱上锁.workflow`。

**没看到菜单项？**

- 打开 **系统设置 → 隐私与安全性 → 扩展 → 访达**，确认"用文件保险箱上锁"勾上；
- 或者注销重新登录一次。

**手动做法（不想运行脚本时）**

1. 打开 **自动操作（Automator）** → 新建 **快速操作**；
2. "工作流程收到当前"选 **文件夹**，位置选 **访达**；
3. 添加"运行 Shell 脚本"，传递输入选"作为自变量"，内容：

   ```bash
   open -a "文件保险箱" "$1"
   ```

4. 存为 `用文件保险箱上锁`。

## 6. 数据位置

| 内容 | 位置 |
|---|---|
| 保险箱本身 | 你选的那个文件夹（`.vault/`） |
| 界面配置 | `~/Library/Application Support/组内工具/文件保险箱/` |
| 审计日志 | 同上目录 `audit.jsonl` |
| 程序日志 | 同上目录 `gui.log` |

## 7. 遇到问题

| 现象 | 处理 |
|---|---|
| 首次打开被拦 | 右键 → 打开；或 `xattr -dr com.apple.quarantine` |
| 提示“另一个窗口正在操作” | 等另一个窗口结束；必要时活动监视器结束 `文件保险箱` |
| 解锁中断/断电 | 重新打开会弹恢复向导，选“继续”或“回滚” |
| 忘了密码 | 用恢复密钥重置；恢复密钥也丢了就**无法恢复** |
| 磁盘不够 | 峰值需要额外“最大单文件 + 32 MiB” |
| 菜单栏没有图标 | 系统设置 → 控制中心/菜单栏 里允许；或先看主窗口是否已打开 |

## 8. 卸载

1. 先把所有保险箱**上锁**；
2. 把 `文件保险箱.app` 拖到废纸篓；
3. 如需要，删除 `~/Library/Application Support/组内工具/文件保险箱/`；
4. 保险箱文件夹里的 `.vault/` 不要删——那是你的数据。
